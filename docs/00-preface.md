# 前言：为什么我要学习量化交易

我不确定自己能不能做好量化交易。

市场充满变化，也充满刺激。投入时间学习，不一定能带来理想的财务回报，写出来的策略也不一定能够赚钱。那么，我为什么还要学习它？

首先是因为向往。

我听说过对冲基金，也听说过这个行业里拥有巨额财富的人。这些故事让我对量化交易产生了好奇：这个行业究竟是如何运作的？交易者依据什么作出决策？策略如何被设计、验证和执行？那些看起来神秘的模型和系统，背后究竟遵循什么规则？

财富故事是最初吸引我走近量化交易的原因，但它不应该成为我判断这件事是否值得学习的唯一标准。我真正想做的，是揭开它的神秘感，了解市场、金融和交易系统是如何运转的。

## 从有限的条件开始

我没有庞大的资金，也不具备专业机构拥有的数据、人才和技术条件。我只能从零开始，用有限的资金，一点点学习和尝试。

我会记录自己学到的概念、写过的代码、做过的回测，以及实际操作中遇到的错误。我的策略可能没有赚钱，投入的学习资金也可能发生亏损。但学习允许付费，不代表可以毫无边界地亏损。我需要提前设定一笔完全能够承受损失的学习预算。预算用完，就停止实盘，回到回测和模拟盘，而不是继续追加资金证明自己。

对我来说，真正重要的不只是一条盈利曲线，而是通过这个过程理解市场，形成一套能够验证、复现和复盘的研究方法。

即使最后没有成为一名成功的量化交易者，这段完整而诚实的学习经历，依然是有价值的结果。

## 为什么量化交易吸引一个技术出身的人

我本身是技术出身。

创业期间，我逐渐发现自己并不喜欢商务应酬和营销。相比不断向外推销，我更喜欢和产品打交道：研究问题、设计功能、观察反馈，然后持续优化和迭代。

这既是我的优势，也是我的缺点。

如果过于沉浸在产品和技术里，就可能忽略真正的市场需求，最后做出一个自己满意、但用户并不需要的产品。

量化交易吸引我的地方，是它提供了一种相对直接的反馈方式。策略是否有效，不只依靠表达和包装，而是要接受数据和市场的检验。收益、回撤、交易成本和稳定性，都会暴露策略真实的表现。

我喜欢这样的工作方式：

```text
提出假设
→ 编写策略
→ 历史验证
→ 发现问题
→ 优化算法
→ 再次验证
```

它很像做产品，只是市场成为了最严格的测试环境。

## 我想建立的不是一台赚钱机器

一个好的量化系统，并不是只要把代码写好，就能自动找到市场，更不是一台可以永久赚钱的机器。

一个策略可能在过去有效，却在未来失效；可能在小资金下成立，资金扩大后却无法执行；也可能在回测中表现不错，最终却被手续费、滑点、Gas 和风险事件吞噬。

因此，我真正想建立的，是一套可以持续研究、验证、执行和复盘的系统。它不负责替我预测未来，而是帮助我按照明确、经过验证的规则处理数据和作出决策。

如果这套系统最终足够成熟，它也许能够减少情绪化操作和重复劳动，让我把更多时间留给健身、旅行以及其他更值得投入的事情。

但自由不是量化交易天然带来的结果。自动化也不等于躺赚。数据可能异常，交易接口会发生变化，市场结构和策略本身也会变化。真正的自由，只能来自可靠的系统、严格的风险控制和长期维护。

我向往的不是不用工作，而是把重复决策交给系统，把自己的时间留给更值得投入的事情。

## 这本书怎样才算完成

这本书有两个彼此独立的目标。

第一个是交易目标：我能否建立经过验证的策略，并获得与风险相匹配的收益。

第二个是学习目标：我能否真正理解市场，掌握数据、回测、风险管理和链上研究方法，并把整个过程清楚、诚实地记录下来。

第一个目标可能失败，但第二个目标完全可以实现。

因此，这不是一本承诺盈利的书，也不是一份展示成功结果的包装材料。它记录的是一个普通技术人员如何从零开始认识量化交易和 Web3，如何犯错、修正、验证，并逐渐建立自己的判断。

量化交易首先是风险管理，其次才是寻找收益。

这将是我整个学习过程的起点。
