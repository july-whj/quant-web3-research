## 这不是一本“告诉你买什么”的书

这本书关注的是一套能够反复运行的研究方法：如何获得数据、提出假设、编写规则、完成回测、扣除成本，并在结果不理想时找到原因。

## 当前进度

第一部分“交易与量化基础”和第二部分“Web3 基础”已经形成初稿；第三部分将持续根据开源系统的真实开发过程补充。章节仍会校对和修订，欢迎通过 GitHub 提交问题或修正。
