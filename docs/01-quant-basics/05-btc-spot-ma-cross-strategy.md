# 第五章：编写第一个 BTC 现货双均线策略

## 5.1 这一章先做一件简单的事

上一章已经获取了第一份 BTC/USDT 日线数据，并保存到了本地。现在，数据不再只是表格。它要开始产生交易信号。

本章要编写第一个策略：BTC 现货多头双均线策略。

这个名字看起来有点长，其实可以拆成三部分：

```text
BTC：交易对象
现货多头：只买入现货，不做空，不使用杠杆
双均线：用两条均线判断趋势强弱
```

本章的目标不是证明双均线策略一定赚钱。它只是第一个可以写清楚、可以用代码生成信号、可以在下一章继续回测的策略样本。

这一步很重要。学习量化交易，不能只停留在“我觉得会涨”或者“这个指标看起来不错”。策略必须被写成规则，规则必须能被数据执行。

本章只完成三件事：

```text
理解现货多头
→ 理解双均线策略
→ 用 Python 生成买入和卖出信号
```

完整收益、资金曲线、手续费和滑点，留到后面的章节处理。

## 5.2 什么是现货多头

现货交易，就是直接买入并持有某个资产。

比如用 USDT 买入 BTC。买入之后，账户里持有的是 BTC。BTC 价格上涨，账户价值上升；BTC 价格下跌，账户价值下降。

多头，是交易方向。做多的含义很直接：希望资产价格上涨。

所以，现货多头可以理解为：

```text
看好 BTC 后续上涨 → 用 USDT 买入 BTC
趋势变弱或不再持有 → 卖出 BTC，回到 USDT
```

这一章只做现货多头。也就是说，账户只有两种状态：

```text
持有 BTC
持有 USDT
```

没有第三种状态。不借钱，不开合约，不做空，也不使用杠杆。

这样做不是因为现货多头最强，而是因为它最适合作为第一个策略。交易方向简单，风险边界更容易理解，代码也更容易检查。

## 5.3 除了现货多头，还有哪些操作类型

交易市场里有很多操作方式。先认识它们，有助于理解为什么本章只选择最简单的一种。

| 操作类型 | 含义                    | 本书当前是否使用 |
| ---- | --------------------- | -------- |
| 现货多头 | 买入并持有资产，价格上涨时获利       | 使用       |
| 现货空仓 | 不持有风险资产，主要持有 USDT 等资产 | 使用       |
| 做空   | 价格下跌时获利，通常需要借币或使用合约   | 暂不使用     |
| 杠杆交易 | 借入资金或资产放大仓位           | 暂不使用     |
| 合约交易 | 交易价格涨跌合约，不一定持有现货资产    | 暂不使用     |
| 套利   | 利用不同市场或不同资产之间的价差      | 后续再研究    |
| 网格交易 | 在价格区间内反复低买高卖          | 后续再研究    |
| 定投   | 按固定时间或规则分批买入          | 可作为对比策略  |

这些方式并不是越复杂越高级。复杂交易会带来更多变量：保证金、爆仓线、资金费率、借贷成本、滑点、订单簿深度、执行失败、API 风险。

第一个策略故意避开这些变量。

对零基础读者来说，先把现货多头跑通，比一开始研究合约和杠杆更稳。一个只能在简单场景里算清楚的系统，不应该过早进入复杂场景。

## 5.4 什么是技术指标

技术指标，是把价格、成交量等市场数据加工成更容易观察的数值或曲线。

例如，收盘价每天都在变，直接看一串价格很难判断趋势。均线会把过去一段时间的价格取平均，把短期噪声过滤掉一部分。这样，价格和均线之间的关系就可以变成规则。

技术指标不是预言机。

它不能保证未来价格上涨或下跌。它只是把已经发生的数据用另一种方式展示出来。真正重要的是：这个指标能否形成清楚的规则，能否回测，能否和基准比较，能否在加入成本后仍然有意义。

很多初学者会被指标数量吸引。今天看到 MACD，明天看到 KDJ，后天又看到 RSI 和布林线。每个指标看起来都有道理，但如果同时堆在一个策略里，往往会变成另一个问题：规则太多，解释不清，回测结果也更容易被参数调出来。

本章只使用均线。先把一件事做清楚。

## 5.5 常见技术指标地图：先认识，不急着全用

技术指标很多。列出的 10 个指标，是很多交易者入门时都会接触到的内容。这里先把它们放在一张地图里，知道它们大概解决什么问题即可。

| 指标        | 通俗理解                    | 使用时要注意               |
| --------- | ----------------------- | -------------------- |
| K 线       | 记录一段时间内的开盘价、最高价、最低价和收盘价 | 它是基础数据，不是单独的买卖答案     |
| 均线 MA     | 观察一段时间内的平均价格            | 滞后于价格，震荡行情容易反复失效     |
| 成交量 VOL   | 观察市场交易活跃程度              | 放量不必然上涨，缩量不必然下跌      |
| MACD      | 观察趋势强弱和变化               | 参数不同结果不同，信号也会滞后      |
| KDJ       | 偏短线的超买超卖指标              | 反应灵敏，也更容易出现假信号       |
| RSI       | 衡量价格相对强弱                | 超买不代表马上下跌，超卖不代表马上上涨  |
| BOLL 布林线  | 观察价格相对波动区间的位置           | 突破上下轨不一定是反转，也可能是趋势延续 |
| 换手率       | 股票中常用于观察交易活跃度           | 加密资产口径不统一，使用时要确认计算方法 |
| 量比        | 比较当前成交量和过去平均成交量         | 更适合短周期观察，不能脱离价格结构    |
| 支撑位 / 压力位 | 观察价格容易止跌或受阻的位置          | 很多时候带有主观画线成分         |

这张地图的作用是建立方向感，不是让本章一次讲完所有指标。

本章只展开均线 MA。原因很现实：均线公式简单，信号清楚，代码容易写，也很适合作为第一个可回测策略。

## 5.6 什么是均线 MA

均线，就是过去 N 根 K 线收盘价的平均值。

如果使用日线，MA5 就是最近 5 天收盘价的平均值；MA20 就是最近 20 天收盘价的平均值。

公式可以写成：

```text
MA5 = 最近 5 天收盘价之和 ÷ 5
```

举一个简单例子。最近 5 天 BTC 收盘价分别是：

```text
100、102、101、105、107
```

那么 MA5 是：

```text
(100 + 102 + 101 + 105 + 107) ÷ 5 = 103
```

每天向前推进一格，就会得到新的 MA5。把这些点连起来，就是均线。

常见均线有：

| 均线 | 含义 |
|---|---|
| MA5 | 短期均线，反应快，但容易受噪声影响 |
| MA10 | 短期趋势参考 |
| MA20 | 更接近中短期趋势 |
| MA60 | 更偏中长期趋势 |

加密市场全年交易，和股票市场存在休市差异。但均线计算逻辑不变：都是对过去 N 根 K 线的收盘价取平均。

均线的价值不在于预测最低点和最高点。它更像是观察趋势的一把尺子：价格在平均成本之上还是之下，短期平均价格有没有超过长期平均价格。

## 5.7 什么是双均线策略

双均线策略使用两条均线。

一条短期均线，一条长期均线。

短期均线反应更快，长期均线反应更慢。当市场上涨时，短期均线通常会更早上行；当市场下跌时，短期均线也会更快下行。

本章使用：

```text
短期均线：MA20
长期均线：MA60
```

策略逻辑是：

```text
MA20 上穿 MA60 → 趋势可能转强 → 买入 BTC
MA20 下穿 MA60 → 趋势可能转弱 → 卖出 BTC
```

短期均线上穿长期均线，常被称为金叉。

短期均线下穿长期均线，常被称为死叉。

这些名字听起来很有交易味，但不要被名字影响判断。金叉不是上涨保证，死叉也不是下跌保证。它们只是把两条均线的位置变化变成了明确的信号。

双均线策略本质上是趋势跟随。它不试图买在最低点，而是在趋势已经表现出来以后跟随。代价是滞后。优势是规则简单。

## 5.8 为什么第一个策略选择双均线

双均线不是最神秘的策略，也不是最强的策略。它适合作为第一个策略，主要因为它足够清楚。

它至少有几个优点。

第一，规则简单。只需要收盘价和两条均线。

第二，容易写成代码。Pandas 的 `rolling().mean()` 可以直接计算均线。

第三，容易画图检查。价格、MA20、MA60、买入点和卖出点都可以放在同一张图上。

第四，适合和买入持有比较。如果一套趋势策略连 BTC 买入持有都比不过，就需要继续分析它到底改善了什么。

但它也有明显缺点。

它是滞后指标。金叉出现时，价格可能已经涨了一段。

它害怕震荡行情。价格反复横盘时，短期均线和长期均线可能来回交叉，导致策略频繁买卖。

它对参数敏感。MA10/MA30、MA20/MA60、MA50/MA200，结果可能完全不同。如果为了得到漂亮回测不断调整参数，就会走向过拟合。

所以，本章选择双均线，不是因为它完美，而是因为它适合练习完整的量化流程。

## 5.9 把策略规则写清楚

策略必须先写成规则，再写成代码。

如果规则都没有写清楚，代码只是把模糊想法自动化。那不是量化交易，只是自动执行模糊判断。

本章的策略规则如下：

| 项目 | 规则 |
|---|---|
| 交易对象 | BTC/USDT |
| 数据来源 | 第 4 章保存的交易所日线 K 线 |
| 数据周期 | 1d |
| 交易方向 | 只做现货多头 |
| 短期均线 | MA20 |
| 长期均线 | MA60 |
| 买入条件 | MA20 上穿 MA60 |
| 卖出条件 | MA20 下穿 MA60 |
| 持仓状态 | 满仓 BTC 或空仓 USDT |
| 初始资金 | 下一章回测时设置 |
| 手续费和滑点 | 第 7 章加入 |

本章先不处理仓位金额，也不处理手续费。它只回答一个问题：

```text
哪一天出现买入信号？
哪一天出现卖出信号？
```

这个边界必须明确。策略学习要分层推进，不能在第一步就把所有问题混在一起。

## 5.11 计算 MA20 和 MA60

Pandas 可以直接计算移动平均线。

```python
df["ma20"] = df["close"].rolling(window=20).mean()
df["ma60"] = df["close"].rolling(window=60).mean()

print(df[["close", "ma20", "ma60"]].tail())
```

`rolling(window=20)` 表示每次取最近 20 行数据。因为这里使用日线，所以它对应最近 20 根日 K 线。

前 19 行无法计算 MA20，前 59 行无法计算 MA60，因为当时还没有足够的数据。这些位置会显示为 `NaN`。

`NaN` 不是错误。它表示数据不足。

在策略里，均线还没有形成之前，不应该生成交易信号。

## 5.12 生成持仓信号

先写最简单的趋势状态：

```python
df["trend_up"] = df["ma20"] > df["ma60"]

print(df[["close", "ma20", "ma60", "trend_up"]].tail())
```

当 `trend_up` 为 `True` 时，表示 MA20 在 MA60 上方。策略认为趋势偏强。

当 `trend_up` 为 `False` 时，表示 MA20 不在 MA60 上方。策略不持有 BTC。

这里要先区分两个概念。

```text
趋势状态：MA20 是否在 MA60 上方
交叉信号：MA20 是否刚刚上穿或下穿 MA60
```

`MA20 > MA60` 只能说明当前短期均线在长期均线上方，它本身不是“金叉”。真正的金叉必须比较前后两天的均线位置。

一根日线的收盘价，要到这一天结束后才知道。MA20 和 MA60 也是在收盘价确定后才能计算出来。如果在回测里使用当天收盘后的信号，却假设自己已经用当天收盘价完成交易，就会发生未来函数。

所以，`trend_up` 只是当天收盘后看到的趋势状态。真正的持仓要等买入和卖出信号生成后，再向后移动一期处理。

## 5.13 找出买入和卖出信号

现在可以找出均线交叉的位置。

先取上一期 MA20 和 MA60：

```python
previous_ma20 = df["ma20"].shift(1)
previous_ma60 = df["ma60"].shift(1)
```

买入信号是：上一期 MA20 小于或等于 MA60，这一期 MA20 大于 MA60。

```python
df["buy_signal"] = (
    (previous_ma20 <= previous_ma60)
    & (df["ma20"] > df["ma60"])
)
```

卖出信号是：上一期 MA20 大于或等于 MA60，这一期 MA20 小于 MA60。

```python
df["sell_signal"] = (
    (previous_ma20 >= previous_ma60)
    & (df["ma20"] < df["ma60"])
)
```

这比直接比较 `signal` 更严谨。因为在 MA60 刚刚开始有值时，如果 MA20 已经在 MA60 上方，旧写法会把“第一次出现可计算状态”误判成买入信号。严格的金叉必须看到上一期和这一期的相对位置发生变化。

接着把买入和卖出信号转换成持仓。

```python
df["target_position"] = pd.Series(
    index=df.index,
    dtype="float",
)

df.loc[df["buy_signal"], "target_position"] = 1
df.loc[df["sell_signal"], "target_position"] = 0

df["position"] = (
    df["target_position"]
    .ffill()
    .fillna(0)
    .shift(1, fill_value=0)
    .astype(int)
)

print(df[["buy_signal", "sell_signal", "position"]].tail())
```

这里的 `target_position` 表示当天收盘后希望调整到的仓位。`position` 向后移动一期，表示下一根 K 线才真正持有这个仓位。

查看信号数量：

```python
buy_count = df["buy_signal"].sum()
sell_count = df["sell_signal"].sum()

print(f"买入信号数量：{buy_count}")
print(f"卖出信号数量：{sell_count}")
```

查看最近几次买入信号：

```python
print(df.loc[df["buy_signal"], ["close", "ma20", "ma60"]].tail())
```

查看最近几次卖出信号：

```python
print(df.loc[df["sell_signal"], ["close", "ma20", "ma60"]].tail())
```

这里得到的不是交易收益，只是交易信号。

本章先到这一步。收益、资金曲线、最大回撤和交易成本，会在第 6 章、第 7 章继续计算。

## 5.15 为什么本章不急着计算收益

看到买入和卖出信号后，很自然会想立刻计算赚了多少。

这一步可以做，但不适合塞进本章。

原因是，完整回测至少还要回答这些问题：

```text
初始资金是多少？
每次买入用多少资金？
买入价格用哪一天的开盘价、收盘价，还是下一根 K 线价格？
卖出时如何计算资产价值？
手续费是多少？
滑点是多少？
空仓时资金如何处理？
如果买入和卖出信号连续出现，如何避免重复下单？
```

这些问题都不难，但必须严谨。否则回测结果会看起来很完整，实际上埋了很多假设。

所以本书把任务拆开：

```text
第 5 章：写清楚策略规则，生成买卖信号
第 6 章：根据这些信号完成第一次回测
第 7 章：加入手续费、滑点和更真实的资金曲线
```

这不是拖延，而是为了让每一步都能检查。

## 本章小结

现货多头是最适合第一个策略练习的交易方向。它只有持有 BTC 和持有 USDT 两种状态，不涉及做空、杠杆和合约。

技术指标很多，但第一个策略不需要全部使用。本章把 K 线、均线、成交量、MACD、KDJ、RSI、BOLL、换手率、量比、支撑压力位作为指标地图介绍，只深入使用均线。

双均线策略用短期均线和长期均线判断趋势状态。MA20 上穿 MA60 时产生买入信号，MA20 下穿 MA60 时产生卖出信号。

真正重要的是时间关系。当天收盘后才能计算出的趋势状态，不能假设自己已经在当天收盘价成交。用 `shift(1)` 把趋势状态变成下一期持仓，是避免未来函数的基本处理。判断金叉和死叉时，还要直接比较上一期和当前均线，不能把“第一次有足够均线数据”误当成交易信号。

下一章将使用本章生成的信号，完成第一次完整回测，并把策略结果和 BTC 买入持有基准放在一起比较。
