# 第一章：什么是量化交易

## 1.1 我一开始以为：量化就是让电脑自动买卖

在正式学习之前，我理解的量化交易，就是让计算机根据数据进行交易。

计算机可以分析 K 线、成交量和市场资讯，也可以关注利好、利空消息。当它从这些数据中发现机会时，就在价格还没有发生明显变化之前提前埋伏。等条件满足后，系统自动买入或卖出，整个过程尽量不需要人工参与。

这个理解不能说完全错误。它已经包含了量化交易的几个重要特征：使用数据、制定规则、借助计算机处理信息，以及按照条件执行交易。

但它也把几个不同的概念混在了一起：量化交易、算法交易、价格预测和自动执行。

随着学习深入，我发现量化交易真正重要的，不是让计算机准确预测未来，而是把一个交易想法变成一套能够被描述、验证、重复执行并控制风险的规则。

## 1.2 把量化交易说简单：数据、规则和验证

现阶段，我对量化交易的定义是：

> 量化交易是利用市场数据、数学统计方法和计算机程序，将交易想法转化为明确规则，并通过历史数据验证、风险控制和持续复盘来辅助或执行交易决策。

这个定义里有五个关键词。

### 数据

交易决策需要能够被观察和记录的数据，而不是只依赖临场感觉。

### 规则

买入、卖出、观望以及仓位大小，都应该有相对明确的判断条件。

### 验证

策略写出来之后，不能马上认为它有效。首先要用历史数据进行回测，再用没有参与参数调整的数据做样本外验证。

### 执行

规则可以由人来执行，也可以由计算机半自动或全自动执行。自动化程度并不是判断它是否属于量化交易的唯一标准。

### 风险控制

策略不仅要说明什么时候赚钱，还要说明可能亏多少、什么时候停止以及投入多少资金。

因此，量化交易不仅是“用计算机下单”。它更像是一套从提出问题到验证结果的研究方法。

## 1.3 量化不是算命：不必每次都猜中涨跌

我最初认为，量化交易应该在价格上涨之前买入，在价格下跌之前卖出。如果做不到提前判断，好像就不能算一个好的策略。

但实际上，并不是所有量化策略都在预测价格。

有些策略会尝试寻找领先信号。例如分析资金流、新闻情绪、订单簿变化或链上大额转账，希望在价格明显变化前发现异常。

有些策略则不预测，而是等待市场发生变化后再作出反应。例如均线趋势策略通常要等短期均线上穿长期均线后才买入。这时价格可能已经上涨了一段，但策略希望捕捉的是后续趋势，而不是最低点。

还有一些策略关注的并不是价格方向，而是不同市场之间的价差、资产组合的风险、交易成本或者流动性。

所以，量化交易不等于准确预测涨跌。它可以预测，也可以跟随，还可以通过控制风险和配置资金来应对无法预测的市场。

## 1.4 电脑到底在看什么数据

我最先想到的是 K 线和成交量，但量化交易使用的数据范围更广。

### 市场行情数据

- 开盘价、最高价、最低价和收盘价
- 成交量和成交额
- 买卖盘口和逐笔成交
- 波动率、价差和流动性

### 基本面和宏观数据

- 公司收入、利润和负债
- 利率、通胀和就业数据
- 行业和经济周期数据

### 新闻与情绪数据

- 新闻报道和公告
- 社交媒体讨论
- 市场情绪指标
- 利好、利空事件及其传播速度

### Web3 链上数据

- 区块和链上交易
- 活跃地址和新增地址
- 交易所资金流入、流出
- 大额地址持仓变化
- DEX 资金池、交易量和流动性
- Gas、稳定币价格和智能合约事件

数据多并不代表策略就一定更好。每增加一种数据，都要检查它是否真实、完整、及时，以及在当时是否真的能够获得。如果回测时使用了交易发生后才出现的信息，就可能产生未来函数。

## 1.5 量化、算法、自动交易，是一回事吗

这几个概念经常一起出现，但关注点并不完全相同。

| 概念 | 主要关注点 | 示例 |
|---|---|---|
| 量化交易 | 用数据和模型形成、验证交易决策 | 根据均线、动量或链上资金流生成信号 |
| 算法交易 | 用程序决定如何生成和执行订单 | 把一个大订单拆分成多个小订单执行 |
| 自动交易 | 系统按照条件自动完成操作 | 信号出现后自动下单、止损和记录 |
| 高频交易 | 在极短时间内大量计算和交易 | 利用微小价差和速度优势进行交易 |

它们之间会有重叠。一套量化策略可以完全自动执行，也可以只生成信号，由人决定是否下单。一个算法也可能只负责降低大额订单的冲击成本，并不负责预测价格。

对目前的我来说，最重要的不是严格区分每一个专业术语，而是先避免把“量化交易”等同于“全自动预测涨跌”。

## 1.6 一个交易想法，怎样变成可以运行的策略

量化交易不是从写代码开始，而是从一个可以验证的问题开始。

```text
观察市场
→ 提出假设
→ 获取和清洗数据
→ 把假设写成明确规则
→ 历史回测
→ 加入手续费、滑点和风险限制
→ 样本外验证
→ 模拟盘运行
→ 小额实盘观察
→ 记录、复盘和调整
```

例如，我观察到：“当市场形成持续趋势后，短期均线可能会超过长期均线。”

这个想法还不是策略。它至少需要继续明确：

- 使用哪个市场和交易对？
- K 线周期是分钟、小时还是日线？
- 短期和长期均线分别是多少？
- 金叉出现后什么时候买入？
- 死叉出现后是卖出还是做空？
- 每次使用多少资金？
- 手续费和滑点是多少？
- 最大亏损达到多少时停止？

只有把这些问题写清楚，才能进行回测，也才能让别人复现同一个实验。

## 1.7 策略要先找一个对手：基准

一个交易想法写成规则以后，还不能只看它在回测里有没有赚钱。它还要回答另一个问题：如果我不使用这套策略，只采用最简单的做法，结果会怎样？

这个拿来比较的对象，叫作基准。

基准不是为了否定策略，而是为了判断收益从哪里来。假设某个 BTC 策略三个月赚了 8%，单看数字似乎不错。但如果同一时期 BTC 本身上涨了 30%，那这套策略并没有表现得更好。它只是搭上了市场上涨的车，甚至还落后于最简单的买入持有。

最常见的基准有三类。

第一类是绝对基准。比如我要求自己的资金年化至少达到 5%，否则还不如选择更简单、更低风险的方式。

第二类是市场基准。股票策略可以和指数比较，数字货币策略可以和 BTC、ETH 或某个行业指数比较。它回答的是：我的策略有没有跑赢市场本身？

第三类是简单策略基准。比如择时策略要和买入持有比较，资产配置策略要和平均分配比较，定投优化策略要和普通定投比较。它回答的是：我增加的规则到底有没有带来价值？

基准让策略评价变得更清醒。一个策略赚钱，不代表它有效；一个策略亏钱，也不一定完全失败。关键要看它承担了多少风险、付出了多少成本，以及相对于合适的基准有没有做得更好。

这也是量化交易和凭感觉交易的重要区别之一。量化研究不会只停留在“这次赚了”或者“这次亏了”，而是继续追问：如果采用更简单的方式，会不会结果更好？

## 1.8 用三个例子看懂量化交易

### 例子一：BTC 现货双均线策略

规则可以暂时写成：短期均线上穿长期均线时买入 BTC，短期均线下穿长期均线时卖出 BTC。整个策略只做现货多头，不使用杠杆，也不开空单。

这是一个趋势跟随策略。它通常不是提前预测价格，而是在趋势出现后作出反应。

### 例子二：新闻情绪策略

程序收集公开新闻，将内容分类为正面、负面或中性。当情绪指标和成交量同时满足条件时，系统生成交易信号。

这看起来比均线策略聪明，但它也会遇到问题：新闻可能已经反映在价格中，情绪分类可能出错，消息发布时间也不一定等于市场最早知道消息的时间。

### 例子三：稳定币偏离监控

程序持续读取 CEX、DEX 和预言机中的稳定币价格。当价格偏离目标值，并且流动性、Gas 和滑点符合条件时，系统发出提示。

这个系统可以先只做监控，不自动交易。它仍然属于量化研究，因为判断条件和数据处理过程都可以被明确描述和重复验证。

## 1.9 电脑很擅长什么，又不擅长什么

计算机的优势在于速度、重复执行和处理大量数据。

它可以：

- 按照相同标准扫描大量市场数据
- 快速计算指标和回测结果
- 在条件满足时及时生成信号
- 避免因为临时恐惧或贪婪随意改变规则
- 自动记录订单、持仓和策略运行情况

但计算机不会自动知道什么是正确的策略。如果数据存在错误、规则设计不合理，程序只会更快、更稳定地执行错误。

所以，自动化不能代替研究和判断。策略在投入运行前需要测试，运行后也需要持续监控。

## 1.10 量化不是一台稳赚不赔的机器

量化交易不能消除不确定性。

回测表现良好的策略，未来仍然可能亏损；复杂模型不一定比简单规则可靠；使用更多数据，也不意味着一定拥有更多有效信息。

量化交易也不能消除人的责任。数据由人选择，规则由人设计，参数由人调整，风险边界也由人确定。如果我为了得到更漂亮的回测结果而不断修改参数，最终可能只是让策略记住了历史，而不是找到了真正有效的规律。

更重要的是，量化交易不是稳赚系统，也不是快速致富的方法。它只是在不确定的市场中，帮助交易者更有纪律地提出假设、检验想法、控制风险和执行决策。

## 1.11 学完这一章，我重新理解了量化交易

经过第一阶段的整理，我对量化交易的理解发生了变化。

我仍然认为计算机、数据和自动化是量化交易的重要组成部分，但它们不是全部。

> 量化交易不是让计算机替我猜涨跌，而是让计算机按照经过验证的规则处理数据和执行决策。

它的完整价值不只体现在交易信号上，还体现在研究过程、验证方式、风险控制和复盘能力上。

判断一套量化系统是否可靠，不能只问“它赚了多少钱”，还需要继续问：

- 它为什么可能有效？
- 使用了什么数据？
- 是否存在未来函数和过拟合？
- 是否计入了全部交易成本？
- 是否和合适的基准进行过比较？
- 最大可能亏损是多少？
- 在不同市场环境下会发生什么？
- 如果策略失效，我如何发现并停止？

这些问题，也是接下来学习量化交易时需要逐步回答的问题。

## 这一章，我真正弄懂了什么

量化交易以数据和明确规则为基础，通过回测、验证、风险控制和持续复盘来辅助或执行交易决策。它可以自动执行，但不一定必须自动化；它可以尝试预测价格，也可以在市场变化后跟随或调整。

对零基础学习者来说，第一步不是寻找一个稳赚策略，而是学会把自己的想法写成能够验证的规则。

下一章将从最基础的收益率、回撤、复利和风险开始，建立评价策略所需的基本概念。
