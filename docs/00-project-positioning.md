# 项目定位与开源路线

这个项目从“量化交易学习笔记”调整为“开源 Web3 量化交易研究系统”。

书稿仍然保留，但它不再是唯一目标。后续内容要从系统建设中长出来：先有一个可以运行、可以验证、可以复盘的系统，再围绕系统写章节。

项目的核心定位是：

```text
用开源书稿讲清楚概念，
用可运行代码验证概念，
用研究系统沉淀数据、策略、回测、模拟盘和风险控制。
```

这不是收益承诺型交易机器人，也不是信号群。它是面向技术人的 Web3 量化交易学习与研究项目。

## 1. 为什么要调整方向

单纯写书容易出现两个问题。

第一，内容会越来越像教材。概念讲得很多，但读者不知道如何落到代码和系统。

第二，写作范围会不断扩大。量化交易、Web3、链上数据、DEX、风控、交易系统，每个方向都可以写很多。如果没有系统作为边界，内容很容易失控。

调整为开源系统后，写作有了更清楚的判断标准：

```text
系统里用到的内容，优先写。
系统暂时用不到的内容，延后写。
不能运行、不能验证、不能复盘的内容，不作为主线。
```

这样可以避免把项目写成百科。

## 2. 项目最终形态

这个项目最终应该包含三层。

第一层是书稿。

书稿负责解释概念、记录学习路径、说明每个模块为什么这样设计。

第二层是代码实验。

代码实验负责把章节里的计算、数据获取、指标、策略和回测跑通。

第三层是研究系统。

研究系统负责把零散实验组织成可复用结构：

```text
数据获取
数据清洗
指标计算
策略信号
回测引擎
成本模型
风险控制
模拟盘
日志复盘
监控报告
```

书稿解释系统，系统验证书稿。

## 3. 开源部分和商业部分的边界

当前阶段只做开源研究系统，不做订阅系统。

开源部分包括：

- 书稿；
- 本地运行代码；
- 示例数据获取；
- 技术指标；
- 策略模板；
- 回测框架；
- 模拟盘；
- 风险指标；
- 研究报告模板；
- 项目文档。

未来如果商业化，优先考虑托管服务，而不是锁住本地代码。

更合理的商业化方向是：

```text
云端运行
数据缓存
策略监控
告警通知
报告生成
可视化编辑器
私有策略管理
技术支持
```

不优先做“高级赚钱策略订阅”。

策略可以作为教学案例和模板，但不应该包装成收益承诺产品。

## 4. 明确不做什么

为了保持项目边界，当前阶段不做以下内容：

- 不承诺收益；
- 不提供投资建议；
- 不做杠杆和合约实盘；
- 不做高频交易；
- 不做抢跑、三明治攻击或 MEV 机器人；
- 不做新币自动狙击；
- 不在代码仓库保存 API Key、私钥或助记词；
- 不默认开启真实下单；
- 不把回测结果包装成实盘能力；
- 不把策略订阅作为早期商业化核心。

这些边界会写入 README 和风险声明。

## 5. 系统优先的章节原则

第 1-15 章负责打基础。

第 16 章开始，内容要从系统中来。

也就是说，每章都应该对应一个可以在代码里找到的位置：

```text
第 16 章：系统整体架构
第 17 章：CEX 行情数据模块
第 18 章：链上数据模块
第 19 章：数据标准化与指标模块
第 20 章：策略配置与信号模块
第 21 章：回测引擎与报告模块
第 22 章：模拟盘与风控模块
第 23 章：监控、复盘与开源发布
```

每章都要回答三个问题：

```text
系统为什么需要这个模块？
这个模块输入什么，输出什么？
读者如何运行一个最小例子？
```

## 7. V0.1 交付目标

V0.1 不追求功能完整，只要求项目可以公开展示。

V0.1 包含：

- README 初稿；
- 风险声明；
- 第 1-15 章书稿；
- 一个可运行 BTC 双均线回测示例；
- 手续费、滑点和最大回撤计算；
- 明确的后续路线图。

V0.1 不包含：

- 实盘交易；
- 用户系统；
- 订阅系统；
- 策略市场；
- 自动跟单；
- 私钥托管；
- 高级策略收费。

## 8. V0.2 交付目标

V0.2 开始进入系统模块建设。

重点是第 16-23 章：

```text
系统架构
CEX 数据
链上数据
指标与标准化
策略配置
回测报告
模拟盘
监控复盘
```

每一章都要对应一个最小可运行代码。

V0.2 完成后，读者应该可以从零运行一个研究流程：

```text
拉取数据
生成指标
运行策略
完成回测
查看报告
记录复盘
```

## 9. V0.3 交付目标

V0.3 再考虑 Web 平台原型。

Web 平台先做研究工具，不做真实交易平台。

优先功能：

- 策略参数配置；
- 回测结果展示；
- 资金曲线；
- 最大回撤；
- 交易明细；
- 策略运行日志；
- 复盘报告；
- 数据源状态。

实盘接口可以预留，但默认关闭。

完成这两步后，项目就从学习笔记进入开源系统阶段。
