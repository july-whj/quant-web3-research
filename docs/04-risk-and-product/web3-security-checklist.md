# Web3 安全检查清单

## 密钥与账户

- [ ] 私钥和助记词未写入笔记、代码或 Git
- [ ] API Key 只开放完成任务所需的最小权限
- [ ] 学习阶段优先使用只读权限
- [ ] 未使用主钱包进行开发测试

## 网络与合约

- [ ] 已核对 Chain ID
- [ ] 已核对 Token 与协议合约地址
- [ ] 优先在测试网或本地网络验证
- [ ] 理解本次授权额度，没有盲目无限授权
- [ ] 知道如何检查和撤销授权

## 数据与价格

- [ ] 区分 CEX 成交价、DEX 池价格和预言机价格
- [ ] 检查 Token decimals
- [ ] 检查流动性和价格冲击
- [ ] 考虑区块确认、重组与数据延迟

## 成本与风险

- [ ] 计算交易手续费、Gas、协议费和滑点
- [ ] 计算总成本占本金比例
- [ ] 考虑 MEV、抢跑和三明治攻击
- [ ] 不使用杠杆和合约验证未经证明的策略
- [ ] 损失金额处于完全可承受范围内
